## 🚀 How to Deploy to GitHub Pages (`prityd825.github.io`)

Follow these simple steps to deploy this portfolio live on the internet under your personal GitHub URL:

### Step 1: Create a Repository on GitHub
1. Go to [https://github.com/new](https://github.com/new).
2. Set the **Repository name** to:
   ```text
   prityd825.github.io
   ```
   *(Note: Using `yourusername.github.io` gives you a clean root domain without subfolders).*
3. Set visibility to **Public**.
4. Leave "Add a README file" unchecked (we already have everything ready!).
5. Click **Create repository**.

### Step 2: Push Your Code
Open your terminal inside this project directory (`C:\Users\prity.rani\.gemini\antigravity-ide\scratch\prity-portfolio`) and run:

```bash
git remote add origin https://github.com/prityd825/prityd825.github.io.git
git branch -M main
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. On your repository page, click **Settings** (top menu).
2. Click **Pages** in the left sidebar.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Wait 1-2 minutes. Your website will be live at:
   👉 **`https://prityd825.github.io`**

## 💻 Local Development & Preview

To preview the website locally on your computer:

```bash
# Using Python
python -m http.server 8080

# Or using Node.js npx
npx -y serve . -p 8080
```
Then open `http://localhost:8080` in any web browser.
